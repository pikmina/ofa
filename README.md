# Store by Pikmina es una Tienda para Foroactivo. 

Funciona como una lista en un Google Spreadsheets que se muestra directamente dentro de las páginas HTML de Foroactivo.

## Versión 1 de la tienda que contiene:

- Categorías de Producto
- Tipo de Producto
- Precios Producto (dos monedas)
- Filtros por Categorías y Tipo de Moneda
- Búsqueda

El producto Incluye:

- Nombre del Producto
- Categoría
- Tipo de Producto
- Precio Único
- Precio por Niveles
- Descripción
- Notas Adicionales

Notas: No tiene página de opciones por separado.
